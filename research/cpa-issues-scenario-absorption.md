# cpa-multi-plugins Issues 场景吸收（真实生产场景 → 本项目需求/契约映射）

- 数据来源：`mmqz/cpa-multi-plugins`（public）全部 63 条 issue（4 open / 59 closed），
  经 GitHub API 抓取落盘：`research/raw/cpa-issues/issues_page1.json`（2026-10-26）。
- 吸收原则：只吸收**对本项目（AI 标书系统）有映射价值**的真实生产场景；与本项目无关的
  平台适配细节（OAuth 流程、区域端点等）登记为不适用，不做无意义扩张。
- 每条映射给出：真实场景（issue 原文要点）→ 本项目落点（需求/契约/测试）→ 吸收状态。
- 本文档只登记"场景→需求"的映射与证据；实现排期以 verification-plan §7 为准。
